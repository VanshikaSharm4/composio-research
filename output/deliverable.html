Pipeline Architecture

The research pipeline executes four stages sequentially, with each stage producing JSON output consumed by the next:

1

Researcher Agent

Researches individual apps using Composio SDK tools for web search and scraping.

Input: App list (100 apps, 10 per category)Output: app_records.json
2

Verifier Agent

Runs multi-pass verification over collected data, checking evidence URLs.

Input: app_records.jsonOutput: verified_records.json + verification_metrics.json
3

Pattern Analyzer

Pure computation analyzing verified records for cross-app patterns.

Input: verified_records.jsonOutput: pattern_analysis.json
4

HTML Generator

Generates the single-file HTML deliverable from all pipeline outputs.

Input: All JSON outputs + intervention_log.jsonOutput: deliverable.html
